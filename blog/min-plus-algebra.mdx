[Network calculus](https://en.wikipedia.org/wiki/Network_calculus) is often summarised as "queueing theory in the [min-plus algebra](https://en.wikipedia.org/wiki/Min-plus_algebra)". In conventional system theory, a linear time-invariant system is characterised by its impulse response and its output is a *convolution* in the $(+,\times)$ algebra. Network calculus keeps the same structure but replaces addition by minimum and multiplication by addition. This post sets up that algebra.

## 1. Cumulative functions

A flow crossing a system is described by two **cumulative functions**:

- $R(t)$, the number of bits that have *entered* the system in $[0, t]$;
- $R^*(t)$, the number of bits that have *left* the system in $[0, t]$.

Both belong to the set $\mathcal{F}$ of wide-sense increasing functions $f : \mathbb{R}_{\ge 0} \to \mathbb{R}_{\ge 0} \cup \{+\infty\}$ with $f(0) = 0$ (for cumulative functions). Causality and lossless operation give $R^* \le R$.

Two performance quantities are read directly from these curves:

$$
b(t) = R(t) - R^*(t) \qquad \text{(backlog at time } t\text{)}
$$

$$
d(t) = \inf \{\, \tau \ge 0 : R(t) \le R^*(t + \tau) \,\} \qquad \text{(virtual delay at time } t\text{)}
$$

The backlog is the *vertical* distance between the two curves, the virtual delay their *horizontal* distance. For a FIFO system, $d(t)$ is the delay experienced by the last bit that arrived at time $t$.

## 2. The min-plus dioid

The structure $(\mathbb{R} \cup \{+\infty\}, \min, +)$ is a *dioid*: $\min$ plays the role of addition (neutral element $+\infty$) and $+$ the role of multiplication (neutral element $0$). Two properties differ from ordinary arithmetic and are the source of many results:

- $\min$ is **idempotent**: $\min(a, a) = a$;
- there is no inverse for $\min$, so equations are solved by *inequalities* and *closures* rather than by subtraction.

## 3. Min-plus convolution

For $f, g \in \mathcal{F}$, the **min-plus convolution** is

$$
(f \otimes g)(t) = \inf_{0 \le s \le t} \{\, f(t - s) + g(s) \,\}.
$$

Interpretation: to obtain the value at $t$, split the interval $[0, t]$ into two parts and take the cheapest split. The operation has the following properties, all of which are used later.

| Property | Statement |
| --- | --- |
| Closure | $f \otimes g \in \mathcal{F}$ |
| Associativity | $(f \otimes g) \otimes h = f \otimes (g \otimes h)$ |
| Commutativity | $f \otimes g = g \otimes f$ |
| Distributivity over $\min$ | $(\min(f, g)) \otimes h = \min(f \otimes h,\, g \otimes h)$ |
| Neutral element | $f \otimes \delta_0 = f$, where $\delta_0(0) = 0$ and $\delta_0(t) = +\infty$ for $t > 0$ |
| Isotonicity | $f \le f'$ and $g \le g'$ imply $f \otimes g \le f' \otimes g'$ |
| Upper bound | if $f(0) = g(0) = 0$ then $f \otimes g \le \min(f, g)$ |

Two closed forms cover most practical computations:

- **Concave functions.** If $f$ and $g$ are concave with $f(0) = g(0) = 0$, then $f \otimes g = \min(f, g)$.
- **Convex piecewise-linear functions.** If $f$ and $g$ are convex and piecewise linear, $f \otimes g$ is obtained by concatenating their linear segments in order of increasing slope.

The second rule gives the most frequently used identity of the theory: for rate-latency functions $\beta_{R,T}(t) = R\,[t - T]^+$,

$$
\beta_{R_1,T_1} \otimes \beta_{R_2,T_2} = \beta_{\min(R_1,R_2),\, T_1 + T_2}.
$$

## 4. Min-plus deconvolution

The dual operation is the **min-plus deconvolution**

$$
(f \oslash g)(t) = \sup_{u \ge 0} \{\, f(t + u) - g(u) \,\}.
$$

It is not the inverse of $\otimes$, but it satisfies the *duality* (residuation) property

$$
f \oslash g \le h \iff f \le h \otimes g,
$$

which is the min-plus analogue of solving $f \le h \times g$ for $h$. Deconvolution is used in [the fundamental bounds post](/blog/three-fundamental-bounds) to compute the arrival curve of a flow *after* it has crossed a server.

## 5. Sub-additive closure

A function $f$ is **sub-additive** if $f(s + t) \le f(s) + f(t)$ for all $s, t$. The sub-additive closure of $f$ is

$$
\overline{f} = \inf_{n \ge 0} f^{(n)}, \qquad f^{(0)} = \delta_0,\; f^{(n)} = f \otimes f^{(n-1)}.
$$

It is the largest sub-additive function below $f$ (and below $\delta_0$). Sub-additive closures appear naturally in the study of arrival curves: any arrival curve can be replaced by its sub-additive closure without loss of information, as shown in the next post.

## 6. Summary

| Object | Conventional systems | Network calculus |
| --- | --- | --- |
| Signal | $x(t)$ | Cumulative function $R(t)$ |
| "Addition" | $+$ | $\min$ |
| "Multiplication" | $\times$ | $+$ |
| System law | $y = h * x$ | $R^* \ge R \otimes \beta$ |
| Impulse | Dirac $\delta$ | $\delta_0$ (zero at 0, $+\infty$ elsewhere) |

## 7. From the lecture notes

These notes rewrite the handwritten notes taken on the course slides [4] and on the introduction of the book [1], in the order of the course.

### Why a new algebra

Network calculus is a **system theory** for deterministic queuing systems, built like the theory of linear circuits but on a different algebra. The notes on the introduction of [1] pair the two:

| Linear systems (electronics) | Min-plus systems (networks) |
| --- | --- |
| Addition $a + b$ | Minimum $a \wedge b = \min(a, b)$ |
| Multiplication $a \times b$ | Addition $a + b$ |
| Output voltage $y = h \otimes x$, an integral convolution | Output flow $y = \sigma \otimes x$, a min-plus convolution |
| An RC circuit | A greedy shaper (traffic shaper), which delays bits so that the output conforms to $\sigma$ |
| Concatenating two filters: convolve the impulse responses | Concatenating two shapers or servers: convolve their curves |

Traffic is shaped by a constraint (the shaping curve), and the conforming traffic leaves the queue. The difference with circuits: the sum of two input flows is **not** handled linearly, because the bits of two flows compete for the same server.

### Min-plus convolution, step by step

$$
(f_1 \otimes f_2)(t) = \inf_{0 \le s \le t} \left( f_1(s) + f_2(t-s) \right).
$$

- It plays the role of the integral of ordinary convolution, with $\inf$ in place of $\int$ and $+$ in place of $\times$.
- It returns the **greatest lower bound** over all ways of splitting the interval $t$ into $s$ and $t - s$.
- It applies to any wide-sense increasing function of time; no continuity is needed.
- It is associative and commutative, and it is easily computed for the curves used in practice, as a combinatorial problem on their linear pieces.

**Example: two rate-latency curves.** For $\beta_1 = R_1(t - T_1)^+$ and $\beta_2 = R_2(t - T_2)^+$, the convolution is a rate-latency curve again, with the smaller rate and the summed latencies:

$$
\beta_1 \otimes \beta_2 = \min(R_1, R_2)\,\big(t - (T_1 + T_2)\big)^+ .
$$

### The rules of the calculus

Functions may take the value $+\infty$, so that impulses can be written:

$$
\delta_0(0) = 0,\quad \delta_0(t) = +\infty \text{ for } t > 0, \qquad f \otimes \delta_0 = f .
$$

| Property | Statement |
| --- | --- |
| Associative, commutative | $(f_1 \otimes f_2) \otimes f_3 = f_1 \otimes (f_2 \otimes f_3)$, $f_1 \otimes f_2 = f_2 \otimes f_1$ |
| Distributive over min | $f \otimes (g \wedge h) = (f \otimes g) \wedge (f \otimes h)$ |
| Isotone | $f \le f'$ and $g \le g'$ $\Rightarrow$ $f \otimes g \le f' \otimes g'$ |
| Through the origin | $f(0) = g(0) = 0 \Rightarrow f \otimes g \le f \wedge g$ |
| Concave through the origin | $f \otimes g = f \wedge g$ |
| Convex piecewise linear | $f \otimes g$ puts the linear pieces of $f$ and $g$ end to end, sorted by increasing slope |

### Arrival curves in min-plus form

$$
\alpha \text{ is an arrival curve for } R
\iff R(t) \le R(s) + \alpha(t - s)\ \ \forall s \in [0, t]
\iff R \le R \otimes \alpha .
$$

The second form compares two functions instead of checking every pair $(s, t)$. When $\alpha(0) = 0$, the inequality is an equality: $R = R \otimes \alpha$.

**Sub-additive closure.** Any arrival curve can be replaced by

$$
\bar\alpha = \inf\{\delta_0,\ \alpha,\ \alpha \otimes \alpha,\ \alpha \otimes \alpha \otimes \alpha,\ \dots\},
$$

which is sub-additive, $\bar\alpha(s + t) \le \bar\alpha(s) + \bar\alpha(t)$ with $\bar\alpha(0) = 0$, and is still an arrival curve. If a flow sends at most $\alpha(T)$ bits in $T$, then in two intervals of length $T$ it sends at most $\alpha(T) + \alpha(T)$, which may be less than $\alpha(2T)$: the closure keeps the tighter value. A sub-additive curve cannot be improved this way.

**Example.** "At most $L$ bits in any interval of duration $\tau$" is the curve $\alpha(t) = L$ for $t \le \tau$ and $+\infty$ after. Its closure is the staircase

$$
\bar\alpha(t) = L \left\lceil \frac{t}{\tau} \right\rceil ,
$$

a more constraining function that describes the same flows.
