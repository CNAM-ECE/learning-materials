Every bound in this series assumes that each talker respects its arrival curve. Per-Stream Filtering and [Policing](https://en.wikipedia.org/wiki/Traffic_policing_(communications)) ([PSFP](https://1.ieee802.org/tsn/802-1qci/)) is the [TSN](https://1.ieee802.org/tsn/) mechanism that makes that assumption hold. It checks each stream where it enters a [bridge](https://en.wikipedia.org/wiki/Network_bridge) and stops a faulty or malicious talker before it can harm the streams that behave.

## 1. Definition

**Per-Stream Filtering and Policing**, [IEEE 802.1Qci](https://1.ieee802.org/tsn/802-1qci/) (now part of [IEEE 802.1Q](https://standards.ieee.org/ieee/802.1Q/10323/)), applies decisions **per stream** at the ingress. Its purpose is protection against bandwidth violation, malfunction and attack [3]. A frame passes three elements in order, after the stream it belongs to has been identified [3][4]:

1. a **stream filter**;
2. a **stream gate**;
3. a **flow meter**.

## 2. Identifying the stream

<CommonsFigure
  id="vlan-tag"
  caption="Figure 2. An Ethernet frame before and after insertion of the 802.1Q header. The header carries the priority code point (PCP), the drop eligible indicator (DEI) and the VLAN ID (VID). Together with the MAC addresses, these are the fields from which a bridge recognises a stream."
/>

[Ethernet](https://standards.ieee.org/ieee/802.3/10422/) has no stream-ID field. A bridge recognises a stream by matching header fields that were agreed when the stream was set up. The **stream identification** functions defined with [802.1CB](https://1.ieee802.org/tsn/802-1cb/) include [2]:

- destination [MAC address](https://en.wikipedia.org/wiki/MAC_address) and [VLAN](https://en.wikipedia.org/wiki/VLAN) ID;
- source MAC address and VLAN ID;
- [IP](https://www.rfc-editor.org/rfc/rfc791) addresses, protocol and ports, for streams carried over IP.

The match yields a **stream handle**, an internal number that the following tables use. The reservation protocols identify a stream by a talker MAC address plus a 16-bit number. In the data plane, the frames are matched on destination MAC, VLAN ID and priority [5].

## 3. Filter, gate and meter

<SourceFigure
  id="farkas2018-psfp"
  caption="Figure 3. PSFP on the original slide: an incoming frame passes the filter, the time gate (which also sets the internal priority) and the meter before queuing."
/>

| Element | Selected by | Decides |
| --- | --- | --- |
| **Stream filter** | Stream handle and priority (either may be a wildcard) | Which gate and meter apply. Also enforces a **maximum frame size**: an oversized frame is dropped and can block the stream. |
| **Stream gate** | The filter | Whether the frame may pass **now**. The gate opens and closes on a gate control list, like the transmission gates of [802.1Qbv](https://standards.ieee.org/ieee/802.1Qbv/6068/), and can set the frame's **internal priority value (IPV)**. |
| **Flow meter** | The filter | Whether the stream is within its **bandwidth profile**. The meter uses the two-rate, two-bucket profile of [MEF 10.3](https://www.mef.net/resources/mef-10-3-ethernet-services-attributes-phase-3/): committed rate and burst (CIR, CBS) and excess rate and burst (EIR, EBS). Frames are marked green, yellow or red; red frames are dropped, and yellow frames can be dropped or demoted. |

## 4. What PSFP does for the analysis

**It enforces the arrival curve.** The committed rate and burst of the meter form a [token bucket](https://en.wikipedia.org/wiki/Token_bucket), so traffic leaving the meter conforms to the arrival curve $\gamma_{r,b}(t) = b + r t$ of [the arrival curves post](/blog/arrival-curves). Without policing, that curve is a promise. With policing, it is a property of the network.

**It contains faults.** A "babbling idiot" talker that floods the network loses its excess frames at the first bridge. Streams that share later queues with it keep their bounds.

**It is a building block.** The stream gate's ability to set the internal priority on a timetable is exactly what [Cyclic Queuing and Forwarding](/blog/cyclic-queuing-and-forwarding) uses to alternate between two queues. The stream filter and gate are also reused in front of the [ATS shaper](/blog/asynchronous-traffic-shaping), which delays frames instead of metering them.

## 5. Summary

| Property | Per-Stream Filtering and Policing |
| --- | --- |
| Standard | IEEE 802.1Qci, now in IEEE 802.1Q |
| Acts on | The ingress port, per stream |
| Elements | Stream filter, stream gate, flow meter |
| Needs time synchronisation | Only for time-based stream gates |
| Metering model | MEF 10.3 bandwidth profile (CIR, CBS, EIR, EBS) |
| Role in the analysis | Makes the declared arrival curve an enforced one |
